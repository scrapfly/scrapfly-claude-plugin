## Claude Code rules

Use the MCP `screenshot` tool for a page or element capture. Use
`capture: "fullpage"` for a full page or a CSS selector in `capture` for an
element. Set `resolution`, `country`, `rendering_wait` and `format` from the
request, and dark mode or banner blocking in `options`, instead of opening a
browser just for an image. Read the returned cost and any error code with its
documentation link.
